Esse projeto pretende calcular o consumo mensal de aparelhos na relação consumo-energia

Este fora feito em linguagem *Python*.

A fórmula utilizada para tal é, respectivamente: (potencia_do_aparelho * tempo_medio_de_uso_por_dia * 30) / 1000. 

Para executar esse programa o usuário deve informar o nome do aparelho, inserir a potência do aparelho em watts (sem inserir letras) e o consumo diário em horas deste aparelho.
